# 🍱 오늘의 급식 평가판

5,6학년 A반 친구들이 오늘 급식 메뉴마다 별점(1~5)과 한 줄 후기(50자)를 남기고, 반 평균을 함께 보는 웹사이트예요.
백엔드는 **Python FastAPI + SQLite**, 화면은 **HTML·CSS·JavaScript**(프레임워크 없음)예요. 컴퓨터 한 대에서 명령어 하나로 켜져요.

- 학생 화면: http://localhost:8000 → 반 입장 → 오늘의 급식 → 메뉴 상세
- 선생님 화면: http://localhost:8000/admin.html → 메뉴 확인·고치기 · 후기 관리 · 학생/입장 코드
- 나이스 급식은 **서버가 매일 아침 9시에 지난 30일치를 스스로 불러와요.** 9시에 컴퓨터가 꺼져 있었으면 서버를 켤 때 바로 불러와요.
- API 문서: http://localhost:8000/docs (FastAPI 가 자동으로 만들어 줘요)

## 실행하기

### 1. 준비물
- Python 3.10 이상 (`python3 --version` 으로 확인)

### 2. 설정 파일 `backend/.env`
`backend/.env.example` 을 `backend/.env` 로 복사하고 채워요.

| 이름 | 내용 |
|---|---|
| `NEIS_API_KEY` | 나이스 교육정보 개방 포털에서 받은 인증키 |
| `NEIS_ATPT_OFCDC_SC_CODE` | 교육청 코드 (서울 `B10`, 부산 `C10`, 대구 `D10`, 인천 `E10`, 광주 `F10`, 대전 `G10`, 울산 `H10`, 세종 `I10`, 경기 `J10`, 강원 `K10`, 충북 `M10`, 충남 `N10`, 전북 `P10`, 전남 `Q10`, 경북 `R10`, 경남 `S10`, 제주 `T10`) |
| `NEIS_SD_SCHUL_CODE` | 학교 코드 7자리. [나이스 포털](https://open.neis.go.kr) → 학교기본정보에서 학교 이름으로 찾아요 |
| `TEACHER_PASSWORD` | 선생님 화면 비밀번호 (4글자 이상, 직접 정해요) |

`.env` 는 비밀 정보라서 깃에 올리지 않아요 (`.gitignore` 에 들어 있어요).

### 3. 설치하고 켜기
```bash
cd lunch-board/backend
python3 -m venv .venv
source .venv/bin/activate        # 윈도우: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
브라우저에서 http://localhost:8000/admin.html 을 열어요. `.env` 를 고쳤으면 서버를 껐다(Ctrl+C) 다시 켜요.

### 4. 처음 쓰는 순서 (선생님)
1. `admin.html` 에서 비밀번호로 로그인
2. **학생 · 입장 코드** 탭 → **코드 만들기** → 칠판에 쓰기
3. **메뉴** 탭에서 자동으로 채워진 메뉴를 확인하고, 틀린 메뉴만 고친 뒤 **저장**

같은 와이파이의 태블릿에서 들어오게 하려면 `uvicorn app.main:app --host 0.0.0.0` 으로 켜고, 태블릿에서 `http://선생님컴퓨터IP:8000` 으로 들어와요.

│   │   └── textfilter.py    금지어·전화번호·링크 검사

## PRD 기능과 코드 연결

| ID | 기능 | 어디에 |
|---|---|---|
| F1 | 반 입장 (입장 코드 + 닉네임) | `POST /api/join` |
| F2 | 오늘 메뉴, 평균 별점, 평가 수 | `GET /api/days/{날짜}` (화면이 5초마다 새로 불러와요) |
| F3 | 별점 주기 (한 메뉴 한 사람 한 번, 다시 누르면 점수만 바뀜) | `PUT /api/menus/{id}/review`, DB 의 `UNIQUE(menu_id, student_id)` |
| F4 | 한 줄 후기 50자 + 금지어 검사 | `textfilter.py` (서버에서 검사) |
| F5 | 후기 목록 (최신순, 닉네임만) | `GET /api/days/{날짜}` |
| F6 | 메뉴 직접 입력·수정 | `PUT /api/teacher/menus/{날짜}` |
| F7 | 신고 3회 자동 숨김, 선생님 숨기기·되살리기 | `POST /api/reviews/{id}/report`, `PATCH /api/teacher/reviews/{id}` |
| F8 | 내 후기 고치기·지우기 (그날만) | `PUT`/`DELETE /api/menus/{id}/review` |
| F9 | 지난 급식 보기 (보기만) | 화면의 날짜 ◀ ▶ |
| F10 | 나이스 급식 자동 불러오기 (매일 9시, 지난 30일) | `sync.py`, 결과는 `GET /api/teacher/neis-status` |
| 2차 | 후기 좋아요 (한 사람 한 번, 내 글·숨긴 글은 안 됨) | `PUT`/`DELETE /api/reviews/{id}/like` |
| 2차 | 나이스 학사일정 (오늘 행사, 방학·재량휴업일이면 "○○이라 급식이 없어요") | `sync.py` 가 급식과 함께 지난 30일~앞으로 30일 일정을 불러와요 |

## 안전 장치

- 이름·이메일·전화번호를 받지 않아요. 학생은 닉네임과 브라우저에 저장된 무작위 토큰으로만 구분해요 (DB 에는 토큰의 해시만 저장).
- 입장하지 않은 사람은 메뉴도 후기도 볼 수 없어요.
- 금지어·전화번호·링크·주소는 서버에서 검사해서 저장 자체를 막아요. 선생님이 반에서만 막을 말을 추가할 수 있어요.
- 숨긴 후기는 서버가 다른 학생에게 보내지 않아요. 학생은 신고 수나 숨김을 바꿀 수 없어요.
- 별점과 후기는 그날(한국 시간, 서버 시계 기준)에만 쓰고 고칠 수 있어요.
- 나이스 인증키는 서버에만 있고 브라우저로 보내지 않아요. 로그에도 남기지 않아요.
- 검색 엔진에 나오지 않게 `noindex` 를 넣었어요.

## 테스트

```bash
cd backend
source .venv/bin/activate
pytest
```
테스트는 진짜 `.env` 대신 시험용 값과 가짜 나이스 응답을 써요.

## 알아 두면 좋은 점

- 시간표(나이스 elsTimetable)는 아직 넣지 않았어요. 나이스 시간표는 학년·반 번호(예: 5학년 3반)로 찾는데, "5,6학년 A반"은 그 번호로 정해지지 않아서 어느 반 시간표를 보여 줄지 먼저 정해야 해요.
- 사진 올리기, 채팅, 이메일·전화번호 가입, 후기 댓글은 어린이 안전과 관리 부담 때문에 넣지 않았어요.

- 자동 불러오기는 메뉴가 없는 날만 채워요. 한 번 채운 날은 선생님이 고친 대로 두고 다시 덮지 않아요. 실패하면 30분 뒤 다시 해 보고(최대 3번), 결과는 선생님 화면 메뉴 탭 위에 보여요.
- 시간과 기간은 `.env` 의 `NEIS_SYNC_HOUR`(기본 9), `NEIS_SYNC_DAYS`(기본 30)로 바꿀 수 있어요. 자동 불러오기를 끄려면 `NEIS_AUTO_SYNC=0`.

- 데이터는 `backend/data/lunch.db` 파일 하나에 다 있어요. 지우면 처음부터 다시 시작해요.
- 금지어 검사는 띄어쓰기를 빼고 보기 때문에, 너무 짧은 금지어는 다른 낱말에 걸릴 수 있어요 (예: "죽어" → "호박죽 어때").
- 메뉴가 없는 평일은 "오늘 메뉴가 아직 올라오지 않았어요", 주말은 "오늘은 급식이 없는 날이에요"가 보여요. 방학·재량휴업일은 아직 따로 표시하지 않아요.
- 학생 화면은 실시간 연결 대신 5초마다 새로 불러와요. 한 반 규모에서는 충분해요.
